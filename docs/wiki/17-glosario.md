# 17. Glosario

| Término | Significado |
|---|---|
| **Panel** | La pantalla principal de SocialMod (tecla `K`). |
| **Toast** | Recuadro flotante de notificación, con la cabeza de quien lo origina. |
| **Respuesta Rápida (Quick-Reply)** | Barra inferior para contestar un toast sin pausar el juego (tecla `Y`). |
| **Directo / DM** | Conversación privada entre dos jugadores. |
| **Buzón** | Los mensajes guardados para un jugador desconectado; se entregan al conectarse. |
| **Grupo / Clan** | Comunidad persistente con roles, canales y etiqueta. |
| **Party** | Equipo temporal para una sesión; no se guarda. |
| **Etiqueta / TAG** | 2–5 letras o números que identifican a un grupo (`[TF]`). |
| **Grupo principal** | El grupo cuya etiqueta se muestra sobre tu nombre. |
| **Canal** | Sala de chat dentro de un grupo (`#general`); puede tener un rol mínimo. |
| **Rol** | Rango dentro de un grupo: Líder, Oficial, Miembro, Recluta. |
| **MOTD / Mensaje del día** | Texto que cada miembro recibe al conectarse. |
| **Mensaje fijado** | Mensaje destacado arriba del chat del grupo. |
| **Evento** | Cita programada de un grupo, con avisos 5 minutos antes y al empezar. |
| **Presencia** | Tu estado visible: en línea, ausente, no molestar, invisible. |
| **AFK** | "Away From Keyboard": ausente por inactividad, detectado por el servidor. |
| **Estado personalizado** | Frase corta que acompaña a tu estado. |
| **Mención** | `@nombre` (o `@TAG`) que genera una notificación prioritaria. |
| **`[coords]` / `[item]`** | Palabras clave que el servidor convierte en tu posición o en el ítem de tu mano. |
| **Spy** | Modo opcional en que el staff lee privados; si está activo, se avisa a todos. |
| **Auditoría** | Registro de las acciones de moderación y gestión de grupos. |
| **Retención** | Cuánto tiempo (o cuántos mensajes) conserva el servidor de cada conversación. |
| **Rate limit** | Límite de paquetes por segundo que protege al servidor de abusos. |
| **Protocolo** | Versión del lenguaje de red entre cliente y servidor; si no coincide, el cliente funciona en "solo chat". |
| **Solo chat** | Modo de un cliente sin SocialMod compatible: usa el chat normal y comandos. |
| **Fabric API / LuckPerms / ModMenu** | Dependencia obligatoria / gestor de permisos / pantalla de mods, ver [guía de administradores](15-guia-de-administradores.md). |
| **GUI Scale** | Escala de la interfaz de Minecraft; el panel se adapta a ella. |
